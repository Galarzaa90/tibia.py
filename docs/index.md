# Tibia.py

Tibia.py is a library for parsing HTML content from [Tibia.com](https://www.tibia.com/news/?subtopic=latestnews) into Python objects.

## Features

- Converts data into well-structured Python objects.
- Provides type-consistent attributes.
- Converts all objects to JSON strings.
- Supports asynchronous requests using [aiohttp](https://aiohttp.readthedocs.io/en/stable/).
- Provides standalone parsing methods, allowing you to use any networking library.
- Supports characters, guilds, houses, worlds, and other Tibia.com sections.
